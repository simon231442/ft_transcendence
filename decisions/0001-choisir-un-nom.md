# 0002 — Choisir le nom du projet

- Statut : Accepté
- Date : 2026-11-16
- Décideurs : nroussy, daniefe2, jsurian, srenaud

## Contexte
L'application a besoin d'un nom pour le branding, l'interface, le README
et un éventuel nom de domaine. Les propositions ont été recueillies dans
l'issue #7 (chore(branding): decide the website name), puis discutées
en réunion

## Critères de décision
- Facile à prononcer
- Ne pas imposer de direction artistique au responsable du visuel
- Porter un sens cohérent avec le produit (apprentissage des langues)

## Options envisagées
Les autres propositions de l'issue #7 (memora.ch, memoMaster, memoPraxis,
Lexis, wordRecall, easymemo, vocalist) ont été écartées sans débat

### Option A — Memomais (« mémoire » + « maïs »)
- Pour : nom ludique, ouvre une piste visuelle autour du maïs.
- Contre : impose une direction artistique (le maïs) qui n'inspire pas
  le responsable du visuel

### Option B — Lernilo (« outil d'apprentissage » en espéranto)
- Pour : porte le sens universel et inclusif de l'espéranto.
- Contre : jugé difficile à prononcer

### Option C — Parolilo (espéranto : *parolo* « parole » + *-ilo* « outil »)
- Pour : garde le sens de Lernilo, plus facile à prononcer
- Note : option née pendant la réunion, en combinant B et l'objection
  sur la prononciation

## Décision
Nous retenons **Parolilo** : il respecte les trois critères et c'est le
nom qui faisait le plus consensus. Enjeu faible, l'équipe a suivi la
préférence du Product Owner

## Conséquences
- Nom affiché dans la webapp et dans le README
- Nom de domaine (il est completement disponible)
- Nom de depo sur la forge renome en Parolilo
